About StudyPortal

StudyPortal is a simple, open study hub organized by semester and subject. Students can read notes and past year questions, rate resources, and ask or answer doubts. Verified developer accounts can upload and maintain content, and resolve issues the community reports.

Built with a Node.js/Express + SQLite backend and a framework-free HTML/CSS/JS frontend — see the README in the project files for setup and deployment.
